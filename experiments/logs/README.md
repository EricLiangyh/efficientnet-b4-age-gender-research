# logs：历史训练日志怎样阅读

[返回实验导航](../README.md) · [脚本对应表](../legacy/README.md) · [图表](../../docs/experiments.md)

本目录八个 CSV 分别对应八组历史训练。名称中的 `15`、`35` 表示训练轮数，不同文件不是同一次训练的不同片段。

| 列 | 含义 | 单位 / 解读 |
| --- | --- | --- |
| `epoch` | 当前轮次 | 从 1 开始 |
| `train_loss` | 训练集联合损失 | 年龄损失与加权分类损失，不等同于 MAE |
| `val_loss` | 验证集联合损失 | 需结合当次任务权重解读；不同损失权重下不能只比较总损失 |
| `val_mae` | 验证年龄平均绝对误差 | 岁，越小越好 |
| `val_acc` | 验证分类准确率 | 0～100 百分比，越大越好 |

与新代码的区别：`age_gender/train.py` 输出 `val_accuracy` 为 0～1；`evaluate.py` 的 JSON 使用 `gender_accuracy`，也是 0～1。不要将 98.2 与 0.982 当成不同准确率。

当前图表和摘要读取最后一轮，不表示该轮一定是验证年龄 MAE 最佳轮。日志没有逐张图片的原始预测，也没有原始划分清单；它们支持历史验证数值的来源记录，不单独证明泛化性能。
